What this is. A one-time snapshot comparing the two archived ancestor modules — the original 2008 Lord of the Rings module and the 2009 Homer's LOTR Edit — against the current Legendary LotR module, to find content worth reclaiming.

How to read it. Resrefs are not stable across these forks, so every entry records how it was matched. Only a none match is genuinely missing content; tag, name and fuzzy matches survived under a different resref. The Wiki column links each entry into every module that has a page for it — 2008, 2009 and live — using that module's own resref, so you can open the same creature, item or area side by side across all three editions.

Treat the heuristic matches with care. A name or fuzzy match is a best guess, not a fact. Most are right, but a generic name can pair two unrelated blueprints, so check the match kind before acting on a row.

This is a draft. Nothing here has been migrated yet, and some findings need interpretation rather than action — see the caveats in each section.
